# Каталог Objektart (`ObjType.DAT`)

`ObjType.DAT` — каталог об'єктів (Objektart) з налаштувань CAPLAN, використаний у застосунку лише для показу
назв шарів. Він **не є частиною коду застосунку й не поширюється на умовах GNU GPL v3**, під якими ліцензовано
решту репозиторію (див. `LICENSE` у корені). Права на цей файл належать його власнику; повторне використання
поза цим застосунком потребує дозволу власника.

The Objektart catalog `ObjType.DAT` is a data file used only to display layer names. It is **not part of the
application's source code and is not licensed under the GNU GPL v3** that covers the rest of this repository.
