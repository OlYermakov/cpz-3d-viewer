# Дані CAPLAN (`ObjType.DAT`, `Layer.DAT`, `Linien.DAT`)

Файли з налаштувань CAPLAN (`C:\Cremer\DAT`), використані в застосунку лише для показу креслень:

- `ObjType.DAT` — каталог об'єктів (Objektart): назви шарів і тип лінії;
- `Layer.DAT` — шари з типом лінії (перекодовано з Windows-1252 в UTF-8, вміст без змін);
- `Linien.DAT` — малюнки типів ліній.

решту репозиторію (див. `LICENSE` у корені). Права на ці файли належать їхньому власнику; повторне
використання поза цим застосунком потребує дозволу власника.

The CAPLAN data files `ObjType.DAT`, `Layer.DAT` and `Linien.DAT` are used only to display layer names and
