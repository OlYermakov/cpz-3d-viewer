# CPZ 3D Viewer

Переглядач креслень CAPLAN (Cremer) у форматі `*.CPZ` у 3D.

**Онлайн:** https://olyermakov.github.io/cpz-3d-viewer/ (працює й на телефоні; після першого відкриття — і без інтернету)

## Використання

Відкрийте сторінку за посиланням вище або локально `dist/CPZ-Viewer.html` у Chrome або Edge (подвійним кліком; інтернет не потрібен) і перетягніть у вікно файл `.CPZ`
або натисніть «Відкрити файл…». Можна також відкрити `.CP` разом із `.L` / `.KOR`.

- ЛКМ — обертання, ПКМ — зсув, коліщатко — масштаб (до курсора)
- `F` вписати · `T`/`1` зверху · `2` спереду (з півдня) · `3` збоку (зі сходу) · `4` 3D-вигляд · `O` вигляд без перспективи / перспектива
- `M` вимірювання (похила/горизонтальна відстань, ΔH, ухил, дирекційний кут у ° та gon)
- `N` назви точок · `C` коди точок (Objektart) · `H` висоти · `Esc` скинути
- Шари (Objektart) з кольорами з `.CP`; подвійний клік по шару — показати тільки його
- Типи ліній CAPLAN: тип Objektart з `ObjType.DAT` (поле «Linientyp»), а якщо там «von Layer» — з `Layer.DAT`;
  малюнок типу — з `Linien.DAT` (рухи пера, зокрема подвійні лінії й зубці паркану), перерахований з аркуша
  в метри для масштабу 1:500. Стандартні типи 2–6 у файлах не описані — довжини штрихів виміряно на зображенні
  з довідки CAPLAN (`CAHLP4.CHM`, «Linienmuster»). Вбудовані символи на лініях (квадрати, блискавка, «Ω» у типах
  9, 12–16) відтворено за тим самим зображенням; заливки (`h`) не відображаються
- Колір за шаром або за висотою, перебільшення Z, проєкції точок на сітку, експорт PNG
- DXF (ASCII): лінії, 2D/3D-полілінії, точки, дуги/кола/еліпси, сплайни, 3D-грані (DGM), SOLID, тексти й атрибути,
  власні кольори об'єктів (ACI, true color, «за шаром» / «за блоком») і типи ліній (LTYPE, $LTSCALE),
  блоки з вкладеністю, розміри; кодування з `$DWGCODEPAGE` (кирилиця ANSI_1251) або UTF-8. Шари CAPLAN
  (`L_`/`S_`/`H_` + назва шару каталогу) отримують назви Objektart
- DWG (R13 … 2018+): читається бібліотекою [LibreDWG](https://www.gnu.org/software/libredwg/) (WebAssembly, пакет
  `@mlightcad/libredwg-web`, GNU GPL v3) у фоновому потоці й далі обробляється тим самим кодом, що й DXF.
  Лише на сайті (не з локального HTML-файлу); модуль ≈ 9,5 МБ вантажиться при першому відкритті DWG.
  Спеціальні об'єкти (proxy: Civil 3D тощо), штрихування й растри не відображаються
- Мови інтерфейсу: українська, німецька, англійська (відкривається німецькою; українська й англійська — перемикачем UA · DE · EN, вибір не запам'ятовується)

## Формат CPZ

ZIP-архів, усередині:

| Файл | Вміст |
|------|-------|
| `*.CP` | проєкт: `DATA=L`, `LAYER=<id>\|<колір COLORREF BGR>\|<видимість>\|<товщина>\|…`, `ZOOM=`, `VIEW=` |
| `*.L`  | точки `<Назва> <W> <Rechtswert> <Hochwert> <Höhe> \|<Objektart>\|<атрибути>` та заголовки ліній `<Назва лінії> \|<Objektart>`; точки після заголовка утворюють лінію |
| `*.A`  | осі, поля фіксованої ширини: `<Achsname> 31\|35 <Rechtswert> <Hochwert> <RiWi, gon> <A-Station> <A-Krumm·1000> <E-Krumm·1000> <Länge>` — елементи в плані (31 — пряма, дуга чи клотоїда, 35 — крива Блосса); `<Achsname> 41 <A-Höhe> <E-Höhe> … <A-Station> … <Länge>` — градієнта |

Дуга між двома точками лінії записується рядком після першої точки: `0  <радіус>  <1|0>  .` — знак радіуса задає
напрямок (+ за годинниковою стрілкою, − проти), ознака 1 — більша з двох можливих дуг, 0 — менша; коло — це дві дуги
A→B (1) і B→A (0). Висота на дузі змінюється лінійно.

Осі показуються на шарі «Achsen» (тип лінії шару ACHSEN з `Layer.DAT`) з підписами станцій (`40+170`). Якщо в CPZ є
точки чи лінії, видно лише ділянки осей у межах креслення плюс запас (не менше 30 м), а «Вписати» бере межі креслення.
Висота осі — з градієнти; без неї вісь двовимірна. Стики елементів сходяться точніше 0,5 мм; явні помилки в даних
(кривина, що суперечить напрямку наступного елемента) замінюються сталою кривиною. Для вибраної точки в панелі «Точка»
і в рядку стану показуються станція основи перпендикуляра (`km 40+169.928`) і відстань ліворуч / праворуч (за напрямком
зростання станцій) від кожної осі в межах 100 м; для осі з градієнтою — ще й висота точки над віссю.

Об'єкти з висотою `0.00000` (наприклад, `QuickLn`) вважаються 2D і розміщуються на рівні найнижчої точки.

## Розробка

```
npm install
npm run build    # → dist/CPZ-Viewer.html
npm run watch    # перезбірка при змінах
```

- `src/cpz.js` — читання ZIP (через `DecompressionStream`), парсери `.CP` та `.L`
- `src/axes.js` — осі `.A`: розбір і розрахунок прямих, дуг, клотоїд і кривих Блосса
- `src/dxf.js` — парсер DXF у ту саму модель (точки, лінії, тексти, шари; OCS → світові координати)
- `src/dwg.js`, `src/dwg-worker.js` — читання DWG у фоновому потоці (LibreDWG) → записи DXF → `src/dxf.js`
- `src/main.js` — сцена Three.js, інтерфейс, вимірювання
- `src/i18n.js` — переклади (uk / de / en) та перемикання мови
- `catalog/ObjType.DAT` — каталог Objektart з CAPLAN (`C:\Cremer\DAT\ObjType.DAT`), вбудовується в збірку;
  назви шарів беруться з поля «Bedeutung»
- `catalog/Layer.DAT` (перекодовано з Windows-1252 в UTF-8) і `catalog/Linien.DAT` — шари й типи ліній
  з `C:\Cremer\DAT`; `src/linetypes.js` — їх читання
- `src/objtypes-i18n.js` — переклади назв Objektart українською та англійською
- `src/index.html` — розмітка та стилі (скрипт вбудовується під час збірки)
- `src/sw.js` — service worker для роботи без інтернету: `build.mjs` підставляє список файлів сайту з хешами
  вмісту (`dist/sw.js`); при новій версії завантажуються лише змінені файли

### Іконка

- `icons/icon.svg` — основна іконка (аркуш креслення + 3D-полілінія), `icons/favicon.svg` — спрощена для 16–48 px
- `icons/concepts/` — альтернативні концепти (A «Віяло», C «Скляний куб»)
- `npm run icons` генерує з SVG у `public/` PNG 16/32/48/192/512, maskable-версію для Android,
  `apple-touch-icon.png` і `favicon.ico`; `public/` копіюється в `dist/` під час збірки разом із `manifest.webmanifest`

### Оновлення каталогу Objektart

Скопіюйте новий `C:\Cremer\DAT\ObjType.DAT` у `catalog/`, перезберіть (`npm run build`) і запуште.
Нові назви без перекладу показуються німецькою — додайте їх у `src/objtypes-i18n.js`.
