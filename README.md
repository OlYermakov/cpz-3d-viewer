# CPZ 3D Viewer

Переглядач креслень CAPLAN (Cremer) у форматі `*.CPZ` у 3D.

**Онлайн:** https://olyermakov.github.io/cpz-3d-viewer/ (працює й на телефоні)

## Використання

Відкрийте сторінку за посиланням вище або локально `dist/CPZ-Viewer.html` у Chrome або Edge (подвійним кліком; інтернет не потрібен) і перетягніть у вікно файл `.CPZ`
або натисніть «Відкрити файл…». Можна також відкрити `.CP` разом із `.L` / `.KOR`.

- ЛКМ — обертання, ПКМ — зсув, коліщатко — масштаб (до курсора)
- `F` вписати · `T`/`1` зверху · `2` спереду (з півдня) · `3` збоку (зі сходу) · `4` ізометрія · `O` орто/перспектива
- `M` вимірювання (похила/горизонтальна відстань, ΔH, ухил, дирекційний кут у ° та gon)
- `N` назви точок · `H` висоти · `Esc` скинути
- Шари (Objektart) з кольорами з `.CP`; подвійний клік по шару — показати тільки його
- Колір за шаром або за висотою, перебільшення Z, проєкції точок на сітку, експорт PNG
- Мови інтерфейсу: українська, німецька, англійська (перемикач UA · DE · EN; визначається з мови браузера і запам'ятовується)

## Формат CPZ

ZIP-архів, усередині:

| Файл | Вміст |
|------|-------|
| `*.CP` | проєкт: `DATA=L`, `LAYER=<id>\|<колір COLORREF BGR>\|<видимість>\|<товщина>\|…`, `ZOOM=`, `VIEW=` |
| `*.L`  | точки `<Назва> <W> <Rechtswert> <Hochwert> <Höhe> \|<Objektart>\|<атрибути>` та заголовки ліній `<Назва лінії> \|<Objektart>`; точки після заголовка утворюють лінію |

Об'єкти з висотою `0.00000` (наприклад, `QuickLn`) вважаються 2D і розміщуються на рівні найнижчої точки.

## Розробка

```
npm install
npm run build    # → dist/CPZ-Viewer.html
npm run watch    # перезбірка при змінах
```

- `src/cpz.js` — читання ZIP (через `DecompressionStream`), парсери `.CP` та `.L`
- `src/main.js` — сцена Three.js, інтерфейс, вимірювання
- `src/i18n.js` — переклади (uk / de / en) та перемикання мови
- `src/index.html` — розмітка та стилі (скрипт вбудовується під час збірки)
